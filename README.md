# Pablo Cloud

Interfaz web personal para acceder a una biblioteca audiovisual mediante DeepStorage.

## Publicación gratuita
1. Abrir **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elegir **Deploy from a branch**.
3. Seleccionar la rama `main` y la carpeta `/(root)`.
4. Guardar y esperar la publicación.

URL esperada: https://pablocerrutti.github.io/PABLO-CLOUD/

## Privacidad y límites
- GitHub Pages publica esta interfaz como sitio público. No contiene autenticación real ni almacena archivos.
- Iniciar sesión directamente en DeepStorage. La ventana integrada puede no funcionar si el proveedor bloquea iframes; el enlace externo es la alternativa.
- No introducir contraseñas, tokens ni claves en este repositorio.
- La integración completa mediante API no se presupone disponible en el plan gratuito.
- No usar este portal como única copia de material irremplazable.
